🤖 Core Agent Components
Modular Pipeline
Stage 01
Researcher Agent
  • Parses incoming PDF / LinkedIn resume text.
  • Extracts candidate skill sets & target role profiles (Program Manager, Supply Chain Analyst, etc.).
  • Sources matching job opportunities from LinkedIn.
PyPDF LinkedIn Search Profile Parser
Stage 02
Capability Analyst Agent
  • Calculates precise fit score (0-100%) per job listing.
  • Identifies missing keywords & critical skill gaps.
  • Recommends courses & training to bridge ability gaps.
  • Provides ATS resume keyword tuning advice.
Keyword Matcher Gap Analyzer ATS Optimizer
Stage 03
Cover Letter Writer Agent
  • Triggers for high-fit opportunity matches.
  • Adopts Rebecca Okamoto's TED Talk narrative style.
  • Highlights core abilities, value proposition & authentic enthusiasm over templated filler.
Storytelling LLM Okamoto Style Prompt Markdown Exporter
