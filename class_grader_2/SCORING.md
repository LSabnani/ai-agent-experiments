# Universal Scoring Rubric

Use the following scoring distribution to evaluate the student's implementation against their specification:

- **Structural Integrity (10%)**: Architecture design, proper separation of concerns, and agentic framework/module declaration as required by the specification.
- **Context Extraction & State Management (20%)**: Effective extraction of user parameters, robust state management, and accurate data flow between components.
- **Graceful Failure Handling (10%)**: Robust error handling, validation of edge cases, and graceful recovery from invalid inputs or external API failures without crashing.
- **Completeness (50%)**: Distribute the score across the subtasks outlined in the problem description. Use your own discretion to assign points. Do not use 0.5 points. Use whole points.
- **Code Quality and Documentation (15%)**: Code should be well-structured, commented, and follow good Python practices.
- **Application Quality (5%)**: User experience, responsiveness, and overall visual / functional polish.
