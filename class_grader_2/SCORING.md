# Scoring Distributions
Use the following scoring distribution to evaluate the student's implementation:

- **Structural Integrity (10%)**: Must explicitly declare ParallelAgent and LoopAgent frameworks.
- **Context Extraction & State Management (20%)**: The Scheduler must read critic_feedback from prior iterations to modify the trip successfully.
- **Graceful Failure Handling (10%)**: Must handle impossible inputs (e.g., extremely low budgets) without crashing.
- **Completeness (50%)**: Distribute the score across the subtasks outlined in the problem description. Use your own discretion to assign points. Do not use 0.5 points. Use whole points.
- **Code Quality and Documentation (15%)**: Code should be well-structured, commented, and follow good Python practices.
- **Application Quality (5%)**: Application quality compared to other applications in the internet today.
